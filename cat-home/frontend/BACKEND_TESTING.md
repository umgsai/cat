# CAT 后台 Vue 页面回归测试

本目录下的 Playwright 测试用于验证已迁移到 Vue 的管理后台页面，重点覆盖页面加载、Spring MVC 接口回跳、写操作权限和配置提交链路。

## 运行前准备

1. 启动 CAT 后端应用，默认地址为 `http://localhost:8080`。
2. 确认前端依赖已安装：

```bash
npm install
```

3. 确认测试账号具备后台配置权限。默认账号密码均为 `admin`。

## 常用命令

```bash
npm run test:backend:all
```

该命令会按顺序执行完整后台回归：

- `test:backend`：管理后台只读冒烟测试。
- `test:backend:navigation`：左侧菜单、右上角入口、返回链接和异常配置 tab 导航测试。
- `test:backend:write`：项目、机器分组、业务监控普通写操作。
- `test:backend:xml`：XML 配置页面提交当前内容。
- `test:backend:rule`：应用告警配置新增、编辑、展示、删除。
- `test:backend:permission`：资源权限、用户权限 XML 写入、编辑并恢复。
- `test:backend:validation`：表单 required 校验和 XML 配置非法内容拒绝。

也可以单独执行某一组测试：

```bash
npm run test:backend
npm run test:backend:navigation
npm run test:backend:write
npm run test:backend:xml
npm run test:backend:rule
npm run test:backend:permission
npm run test:backend:validation
```

## 环境变量

```bash
CAT_BASE_URL=http://localhost:8080
CAT_ADMIN_USERNAME=admin
CAT_ADMIN_PASSWORD=admin
CAT_TEST_DOMAIN=cat-codex-test
CAT_TEST_BUSINESS_KEY=codex-test-custom
```

- `CAT_BASE_URL`：后端应用地址。
- `CAT_ADMIN_USERNAME` / `CAT_ADMIN_PASSWORD`：后台登录账号。
- `CAT_TEST_DOMAIN`：写操作测试使用的临时项目名。
- `CAT_TEST_BUSINESS_KEY`：业务监控写测试使用的临时 key。

## 写操作说明

写操作测试会真实提交后台配置，因此不要在生产环境执行。

- `test:backend:write` 会新增并删除测试项目、机器分组和业务监控项。
- `test:backend:xml` 会提交当前 XML 原内容，用于验证提交链路，不主动改变配置。
- `test:backend:rule` 会新增、编辑并删除测试告警规则和异常阈值，并新增删除异常过滤。
- `test:backend:permission` 会先保存原始权限 XML，插入并编辑测试节点提交验证，再恢复原 XML。
- `test:backend:validation` 会提交非法输入或触发浏览器校验，验证失败返回和原配置不被改写。

如果测试中断，优先重新运行对应测试组，清理逻辑会在下一次运行开始和结束时再次执行。

## 建议继续补的测试

1. 表单校验测试：继续补重复项和更多业务语义非法输入，例如异常阈值 warning/error 关系。
2. 编辑已有数据测试：继续补更多普通配置的“打开已有记录 -> 修改 -> 保存 -> 回显”。
3. 权限矩阵测试：使用低权限测试用户验证后台页面和写接口确实会拒绝。
4. XML 语义校验测试：在隔离环境补充结构合法但业务语义非法的配置内容。
5. 高风险副作用按钮单独测试：例如客户端路由的“重算路由”，只在隔离环境执行。
6. UI 交互测试：菜单收起/展开、tab 切换、确认弹窗、CodeMirror 编辑器焦点和隐藏字段同步。

当前测试更适合作为迁移回归和上线前冒烟，不等价于完整业务验收测试。
